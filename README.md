# GitHub Clone

A pixel-faithful static clone of the GitHub homepage/marketing UI, built as a front-end exercise in HTML, Tailwind CSS and vanilla JavaScript. No backend, no build step — open `index.html` and it runs.

## Features

- Dark-themed GitHub-style landing page: hero, nav, feature sections, footer
- Tailwind CSS via CDN for rapid utility-first styling
- Inter font from Google Fonts for authentic GitHub typography
- Fully responsive layout (mobile → desktop)

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript

## Quick Start

No dependencies or build tools required:

```bash
git clone https://github.com/girishlade111/GitHub-Clone.git
cd GitHub-Clone
# open index.html in any browser, or:
python3 -m http.server 8000
# then visit http://localhost:8000
```
